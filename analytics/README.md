Сервис аналитики посещаемости и аномалий

Сервис принимает данные о сайте, записывает данные посещаемости и следит за появлением странного трафика

Прием посещений POST /track с проверкой данных
Определение страны и города через ip-api.com
Выдает отчеты о популярных страницах, популярных странах посетителей сайта, аномалии
Обнаружение странного трафика по Z-score
Сообщает об аномалиях по электронной почте сразу нескольким людям
Хранение данных и аномалий в PostgreSQL
Жокументация API

Используются Python 3.11+, FastAPI, SQLAlchemy 2.0, PostgreSQL 16 (Docker), httpx, python-dotenv

Начало:
внесите данные в .env.example и переделайте в .env

Запустите докер контейнер:
docker compose up -d --wait
установите зависимости из requirements.txt
Подождите около минуты и запускайте
Запуск
uvicorn app.main:app --reload

POST /track Принимает данные о посещении.
GET /reports/popular_pages Топ-5 страниц по итогам визитов за последние 24 часа.
GET /reports/geo_stats Статистика за последние 7 суток
GET /reports/anomalies Обнаружены аномалии, за последние 24 часа
У аномалий есть минимум посещений в 10 чтобы с 1 запроса не отправлялись письма

для проверки можно отправить запрос или сразу 20 для проверки аномалий 
for i in $(seq 1 20); do
  curl -s -o /dev/null -X POST http://127.0.0.1:8000/track \
    -H "Content-Type: application/json" \
    -d "{\"page_id\":\"home\",\"user_id\":\"u$i\",\"ip\":\"8.8.8.8\",\"timestamp\":\"$(date -u +%FT%TZ)\"}"
done
curl -s http://127.0.0.1:8000/reports/anomalies
